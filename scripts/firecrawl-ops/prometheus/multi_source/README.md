## Run it

```bash
# 1. Install a TypeScript runner and the Firecrawl SDK
npm install -g tsx
npm install @mendable/firecrawl-js

# 2. Provide your Firecrawl API key
export FIRECRAWL_API_KEY=fc-...

# 3. Run
tsx script.ts
```

The script prints the collected data as JSON to stdout.
