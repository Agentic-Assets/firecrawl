# Buildout property observations

A bounded Cheerio pass records labels, section body text and links and ordered
broker-card fields inside Buildout overview panels. Multiple roots or panels
remain distinct with ordinals and an explicit ambiguity status. Multiple broker
groups and duplicate cards remain distinct, while a nested card belongs to its
nearest group and panel once. Footer cards and field-selector occurrences within retained cards are excluded
and counted separately; these counts are not source-observation omissions. Card fields
retain ordered occurrences, including nulls and explicit overflow counts;
repeated values mark the card ambiguous. Ambiguous section bodies and
links remain present but unqualified; shared containers may repeat and cannot
be attributed to one label. Static hidden attributes are recorded as
such, without claiming computed visibility. Headers, navigation and footers are
outside the property scope. Field, link, entry and input limits have explicit
omission states; raw HTML and Markdown retention follow existing evidence limits.

Normal enrichment adds the carrier only after matching the configured claim
route to the requested page. Observation mode treats a caller's Buildout-shaped
URL as unverified. Neither mode makes a property identity, primary broker,
access, freshness or canonical field assertion. The generic evidence carrier
remains source-neutral; the normal credential scanner and source-specific
projection must run before persistence, and unsupported sources may refuse.

The generic carrier reports `source_observation_partial` without discarding the
carrier when sections are ambiguous or bounded fields are omitted. A whole
carrier may instead be omitted explicitly if its serialized size exceeds the
existing evidence field limit.
