# Private source evidence output

Read parent collector, source and lib guidance and this folder's README. This
opt-in helper records source-native response evidence, never database writes,
identity resolution, status activation, scheduling or source admission.

Avison website capture is decoded-text local custody only. Never include the
integration key or headers in capture metadata, logs, URLs, or hashes. The
source-owned withheld-price projection and admission policy precede DB retention;
local raw page hashes must not become projected evidence commitments.

Draft Buildout capture is explicitly enabled for 28 registered sources and 29
feeds, including SVN, Lee and separate Franklin sale and lease feeds. The
original 25 native receipt shapes and scope hashes stay unchanged. It stores parsed JavaScript
JSON privately, not HTTP bytes or original numeric precision. Capture and source
clocks are distinct, memory-cache hits do not create fresh capture, and a capture
failure stops the enabled path. Existing source/credential policy remains
separate; Faris collector projection does not apply. Read README for bounds.
This draft is unverified under the hold and not deployed.

`artifact-output.ts` is the shared full/enrich artifact publisher. Artifacts
with retained observations, and all targeted enrichment artifacts, require an
explicit file destination, exclusive creation and mode 0600. Fsync the file
before close; guarded custody separately syncs its private parent directory.
Never send private artifacts to stdout or overwrite a prior capture. Ordinary
full listing output keeps its existing publication behavior.
This is private local custody, not database admission or canonical completion.
