# Docling JSON local supplement

The standalone adapter reads a local PDF and ordered AnyDoc and supported
Poppler artifacts. It retains the original bounded Docling export JSON,
including unknown fields, without interpreting values. It runs a pinned cached
image offline with OCR and generated images disabled. Coverage, publication
authority, identity and extraction accuracy remain unknown.

An explicit acquisition policy v5 can use this adapter through the existing
foreground document coordinator. That path requires sealed priors, a verified
owned-container settlement and parent completion marker before no-spawn replay.
The final seal and append job retain a distinct Docling role and exact UTF-8
chunks. Before admission the coordinator decodes and checks native JSON and
JSON-encoded strings against existing source and credential restrictions.
This is not general secret detection or publisher permission.

The worker processes the first bounded page range. Omitted or unrepresented
pages and partial or failed conversion remain explicit. Under
`keep_unresolved_until_review`, those outcomes retain originals; success still
does not establish fidelity. `temporary_only` retains its selected cleanup
semantics. No new scheduler, source authorization or canonical promotion follows.
This draft is not deployed; production acceptance remains separate.
